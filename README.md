手边有小米手机，电脑却不是小米笔记本。想用电脑操作手机、传送文件、接着粘贴刚复制的文字，却在安装时遇到「暂不支持本设备」。

这个 Skill 将已经验证过的兼容安装流程交给 Agent：**你提供官方 EXE，Agent 负责识别、准备和核对；你决定何时安装，并亲自在官方窗口登录。** 从安装包到手机功能验收，每一步都有明确的结果。

> **当前支持：小米电脑管家 5.8.1.130 的一个精确构建。** 同版本号不一定是同一安装包，Skill 会自动校验。其他版本需要单独适配。本项目为社区工具，与小米无隶属关系。

## 把跨设备协作带到你的日常

| 你想做的事 | 已经验证的体验 |
| --- | --- |
| **在电脑上操作手机** | 查看手机投屏画面，并用电脑鼠标操作 |
| **让文件来回传递** | 电脑发送文件到手机，手机也能把文件传回电脑 |
| **复制一次，跨端接着用** | 电脑与手机双向同步剪贴板测试文字 |
| **使用自己的小米账号** | 在官方窗口退出账号后重新登录成功 |

以上体验来自一台**原先已有小米服务的非小米 Windows 11 电脑**。它们说明这条兼容路径有实机依据；你的电脑仍需逐项验收。长期账号与完整信息同步、平板键鼠共享、电视投屏及全部虚拟音视频能力尚未验证完成。

## 为什么把它交给 Skill

### 少一点摸索，多一点确定

把安装包交给 Agent，它会检查文件大小、完整哈希、原始指令和官方签名，再生成经过校验的兼容副本。**原文件保留不变，遇到不匹配的样本就停止。** 你不需要自己寻找补丁位置，也不需要为这个已支持的构建配置 REA 或 Ghidra。

### 从准备，一直走到真实体验

Skill 串起安装前检查、授权安装、核心文件核对和手机功能验收。它会分别记录「副本生成成功」「安装完成」和「功能实测通过」，让你知道流程到了哪一步、还有什么没验证。

### 账号由你掌握，操作有据可查

你自行在官方登录窗口输入密码与验证码；密码、验证码、账号令牌和会话数据不经 Agent。设备检查报告留在本地，默认不上传；安装前后的记录可供排查问题。需要系统授权或手机确认的环节，由你本人完成。

## 开始使用

准备好一台 Windows 电脑、你自行取得的官方安装包，以及能够读取本地文件、执行命令的 Agent。**安装 Skill 本身不会安装小米软件。**

### 1. 把 Skill 装进你的 Agent

将下面这段话复制给支持 GitHub Skill 安装的 Agent：

```text
请从 https://github.com/WildFrogWorks/xiaomi-pc-manager-skill 安装 Skill。
Skill 位于仓库根目录（路径为 .），名称为 xiaomi-pc-manager-compat-skill。
保留完整的脚本、版本清单和引用文档，阅读 SKILL.md，并按当前 Agent 的要求加载。
本次只安装 Skill，不运行小米安装器或小米程序。
```

Agent 不支持直接从 GitHub 安装时，可通过仓库的 **Code → Download ZIP** 下载，或克隆仓库。将完整目录交给 Agent，要求先阅读 `SKILL.md`；支持技能目录的 Agent 可按自身规则加载。不要只复制单个 `SKILL.md`。

### 2. 提供安装包，先做兼容准备

将下面两处路径替换成自己的实际路径，再发给 Agent：

```text
使用 xiaomi-pc-manager-compat-skill。
官方 EXE 路径：<安装包的完整路径>
工作目录：<用于保存兼容副本和报告的目录>
先完成识别与兼容副本校验，告诉我是否支持，以及安装会改变哪些组件。
此阶段不要运行小米安装器或小米程序。
```

### 3. 确认安装，再连接你的手机

检查结果通过、了解安装影响后，可以继续告诉 Agent：

```text
允许在当前电脑安装并运行验证，使用刚才校验过的兼容副本。
小米账号由我本人登录。请核对核心文件和服务状态，
再引导我测试手机投屏、双向文件互传与双向剪贴板。
```

按提示完成系统授权、本人账号登录和手机端确认。Agent 会整理本次电脑上的实际结果，把已通过、失败和未测试的项目分别列出。

## 使用前请了解

| 项目 | 当前范围 |
| --- | --- |
| 安装包 | 仅支持配置文件中的 **5.8.1.130 精确构建**，由完整哈希识别 |
| 本地环境 | 64 位 Windows、Python 3.10+、64 位 Windows PowerShell 5.1+ |
| Agent 能力 | 能读取完整 Skill、访问本地文件并执行命令；仅能聊天的 Agent 只能提供操作指导 |
| 功能验收 | 手机相关测试需要你自己的兼容设备配合；不同电脑需重新验证 |
| 新版本 | 不自动适配；未知安装包会停止处理，更高版本升级流程尚未验证 |

**安装会涉及服务与虚拟驱动。** 兼容副本的安装器原签名会失效；不要关闭系统防护来运行它，系统若阻止执行，应停止并报告。安装前记录不等于系统备份，卸载主程序也不保证恢复原有服务、驱动和全部设置。需要系统级回退时，请在安装前自行准备合适的备份。

<details>
<summary><strong>它具体改了什么？</strong></summary>

本流程修改的是安装器副本中的一个**静默安装机型资格分支**，并保留前置环境检查。运行时无需持续注入，不修改 BIOS、硬件身份、账号认证或客户端核心文件。

实机验证中，安装后的五个主要客户端文件与原始安装内容一致，且签名有效；这不代表已经审计所有安装产物。交互式安装路径未修改，Skill 按已验证的静默安装流程执行。

完整机制、修改位置与证据见 [版本证据](references/compatibility-evidence.md)。

</details>

<details>
<summary><strong>怎样确认自己的安装包受支持？</strong></summary>

把原包交给 Skill 识别即可。文件名或版本号相同不能代替校验，以下信息供人工核对：

| 项目 | 值 |
| --- | --- |
| 文件大小 | 766,644,624 字节 |
| 原始 SHA-256 | `d812cf30805d172474eb33b2f97f37129593f9d50f09d4224f73d530a2cb40e9` |
| 兼容副本 SHA-256 | `a7d35102dc1abdb5e8a5e45ba43c6a6b22f5b30cd9c456799a5bfea65f210e34` |

校验不通过时，不要改文件名、关闭校验或把已知偏移直接套到其他安装包上。版本配置见 [profiles/5.8.1.130.json](profiles/5.8.1.130.json)。

</details>

<details>
<summary><strong>后续更新和更多设备呢？</strong></summary>

当前还没有完成更高版本下载与安装的完整验收。「已是最新版本」提示不能证明自动升级全过程可用。新增版本需要独立分析、适配和实机验证。

平板键鼠共享、电视投屏、全部虚拟音视频能力及长期账号/信息同步，不在目前已完成的验证范围内。手机投屏中的鼠标操作也不等于平板键鼠共享。详情见 [恢复与更新](references/recovery-and-updates.md)。

</details>
